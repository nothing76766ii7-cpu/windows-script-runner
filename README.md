# Windows Script Runner Android App

Android app with a Windows Explorer style interface to run, preview, and transpile Windows scripts (.bat, .cmd, .ps1, .vbs, .reg, .sh, .py, .js) on Android.

## Features
- Windows 11 File Explorer visual design
- Interactive terminal console
- Script execution bridge
- Batch to POSIX shell transpiler
- Windows Registry environment variable importer
- Runs natively on Android (minSdk 24, Android 7.0+)

## Build
Built automatically with GitHub Actions on `git push`.
Debug APK is published to GitHub Releases and Actions Artifacts.
